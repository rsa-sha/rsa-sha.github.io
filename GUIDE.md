# GitHub Pages Usage Guide

## Folder Structure
- index.html (homepage)
- style.css (global styles)
- projects/
  - store.html
  - sahdb.html

## Adding a New Project Page
1. Create a new HTML file under `projects/`
2. Copy the structure from `store.html`
3. Add a link to it in `index.html`

## Publishing on GitHub Pages
1. Push this repository to GitHub
2. Go to Settings → Pages
3. Select branch: `main`
4. Select folder: `/root`
5. Save — site will be available at `https://<username>.github.io`

## Editing Content
- Use plain HTML for simplicity
- Keep one page per project
- Link GitHub repos clearly
