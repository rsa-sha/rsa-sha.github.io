store

Filesystem-inspired storage engine with a custom on-disk format.

Overview

store explores low-level storage concerns such as disk layout, append semantics, metadata consistency, and crash behavior.

Design Focus

  • Explicit on-disk layout and metadata
  • Correctness under partial failure
  • Predictable behavior under resource constraints
